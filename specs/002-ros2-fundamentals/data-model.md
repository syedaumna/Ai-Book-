# Data Model for ROS 2 Fundamentals Curriculum

This feature is primarily content-focused and does not introduce new data models to be stored in a database. The key entities are conceptual and are described within the curriculum content itself.

## Key Entities

- **Student**: The learner progressing through the curriculum. This entity is not stored in the system.
- **ROS 2 Node**: A fundamental process in the ROS 2 system. Described in the curriculum.
- **ROS 2 Topic**: A named bus for messages. Described in the curriculum.
- **ROS 2 Service**: A request/response communication method. Described in the curriculum.
- **ROS 2 Action**: A long-running, goal-oriented communication method. Described in the curriculum.
- **URDF Model**: An XML file describing a robot's physical structure. Described in the curriculum.
