# Quickstart for ROS 2 Fundamentals Curriculum

This guide provides the basic steps to get started with the ROS 2 Fundamentals curriculum.

## Prerequisites

-   A computer running Ubuntu 22.04 LTS.
-   ROS 2 Humble or Iron installed.
-   Basic knowledge of Python.

## Getting Started

1.  **Navigate to the curriculum**: Open the website and go to the "ROS 2 Fundamentals" section in the documentation.
2.  **Follow the modules**: Start with Module 1 and proceed through the curriculum in order.
3.  **Complete the labs**: The hands-on labs are the most important part of the curriculum. Make sure to complete them to get practical experience with ROS 2.
